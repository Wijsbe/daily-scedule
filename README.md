# 5-Ploegenrooster App

Een React applicatie voor het beheren van je 5-ploegenrooster en dagindeling.

## Functionaliteiten

- Instellen van je dienstpatroon (bijv. 2-2-2-4)
- Aanpassen van individuele diensten
- Instellen van dagindeling per diensttype
- Kalenderweergave van je rooster
- Gedetailleerde dagweergave met activiteiten
- Notificaties voor activiteiten

## Installatie

1. Zorg dat je Node.js en npm geïnstalleerd hebt
2. Clone deze repository
3. Installeer de dependencies:

```bash
npm install
```

4. Start de ontwikkelserver:

```bash
npm run dev
```

5. Open [http://localhost:5173](http://localhost:5173) in je browser (of het adres dat in de terminal wordt weergegeven)

## Benodigde dependencies

- React
- React Calendar
- date-fns

## Gebruik

1. Stel je dienstpatroon in via de "Patroon Instellen" knop
2. Stel je dagindeling in per diensttype via de "Dagindeling Instellen" knop
3. Bekijk je rooster in de kalender
4. Klik op een dag voor gedetailleerde informatie
5. Klik op een dag in de kalender om handmatig de dienst aan te passen
